03 / CONTROL PLANE: NO AUDIO SAMPLES INSIDE CONTROL QUEUE

Actual board rotary / touch / control intent → ControlTaskPCB pins require port; Nucleo B1 PC13 and LD2 PA5 are not on the custom board. Filter user events, map them into compact GroupEvent{type,value} values and xQueueSend(...,0) into 8-entry queue. AudioTask is sole DSP/PCM state writer.
Contextual preference learning · integration phaseRAM table: 3 source × 3 loudness × 3 spectral buckets = 27 contexts. Learn only from explicit up/down feedback. Two valid observations required; cooldown 250 ms; recommend 0.75–1.0 relative Q15 attenuation, never amplify above unity.
